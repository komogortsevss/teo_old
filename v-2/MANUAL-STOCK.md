# Инструкция по управлению цветами и складом

## Как это работает

### 1. Справочник цветов (вкладка "Цветы")
- Создавайте новые цветы кнопкой **"Добавить цветок"**
- Укажите название (например, "Пион") и slug (например, "peony")
- Цветы из справочника используются при составлении букетов

### 2. Складской учёт (вкладка "Склад")
- Показывает остатки всех цветов из справочника
- **Цветовые индикаторы:**
  - 🔴 Красный — 0 стеблей (нет в наличии)
  - 🟠 Оранжевый — меньше 20 стеблей (мало)
  - 🟢 Зелёный — 20 и более стеблей (достаточно)
- Кликните **"Изменить"** для обновления количества

### 3. Состав букета (форма букета)
При создании/редактировании букета:
1. Нажмите **"Добавить цветок"**
2. Выберите цветок из выпадающего списка
3. Укажите количество стеблей
4. Можно добавить несколько разных цветов

**Пример:** Букет "Микс" может состоять из:
- Роза — 5 стеблей
- Альстромерия — 3 стебля
- Диантус — 3 стебля

### 4. Автоматическая проверка доступности
**Система автоматически проверяет:**
- При каждом изменении остатков на складе
- Сравнивает состав всех букетов с остатками
- Если хотя бы одного цветка не хватает → букет становится **"Не в наличии"**

**Букеты без состава** (старые, с пустым полем composition) остаются в том статусе, который установлен вручную.

## Быстрый старт

### Создать новый цветок:
1. Админка → Цветы
2. "Добавить цветок"
3. Название: "Пион", Slug: "peony"
4. Сохранить

### Пополнить склад:
1. Админка → Склад
2. Найдите нужный цветок
3. "Изменить" → укажите количество
4. После сохранения автоматически пересчитается доступность всех букетов

### Создать букет с составом:
1. Админка → Букеты → "Добавить"
2. Заполните основную информацию
3. В секции "Состав букета" добавьте цветы:
   - Роза — 11 шт
   - Альстромерия — 5 шт
4. Сохраните
5. Система автоматически проверит наличие и установит статус

**Готово!** Теперь у вас полноценная система управления составом и складом.
